# Product

## Register

product

## Users
Ren, a solo operator handling 4 to 5 client accounts at once. Uses it on a MacBook during work blocks (main use) and on the phone between calls. The job: see every client's open work in one place, switch into one client's context fast, and tick things off.

## Product Purpose
A personal task and client tracker (static site on GitHub Pages, data in Supabase). Success: Ren opens it at the start of a block and knows what is overdue, what is due today, and what each client is waiting on, without opening Slack, WhatsApp or Outlook first.

## Brand Personality
Premium, warm, focused. Deep plum frame with a coral accent; feels like a tool Ren is proud to have open all day, not a generic SaaS template.

## Anti-references
- Phone layout stretched onto a desktop (the v2 problem: a 480px column on a laptop).
- Pastel glassmorphism and gradient buttons.
- Generic SaaS dashboards with hero-metric tiles.

## Design Principles
1. Desktop first for density, mobile still complete.
2. One click into a client's context; the client is the main unit of work.
3. Color carries meaning (client identity, overdue, status), never decoration.
4. Fast and quiet: state-change motion only.

## Accessibility & Inclusion
WCAG AA contrast in both light and dark themes, keyboard reachable (N = new task, / = search), respects reduced motion.
